- Earnest is the volunteer student who is helping Adrian. He has a surveying background 
  and is analysing the nearmap data. For each site, he is making a table of the recent
  environment. EG can structures such as furrows be seen in the images that reflect land
  management? EG cropping structures that give way to Native veg, etc.

- Earnest has the NSW land managment layers which are developed by the NSW remote sening team.

- It could be that we could develop a generlaized mixed effect model with random factors that
  combines gauge data with remote sensing (RS) data, where the RS data is adjusted using the 
  gauge data. EG a mixed model that says: "Given X water (station), we expect Y inundation (RS).
  The residuals of such a model (more or less flooding than expected from the time series) 
  could start getting at the potential effects of land managemet. EG is the landscape wetter over
  time than expected, due to the removal of irrigation structures from the farm? Jason Evans from
  the UNSW CC CRC has a similar model for rainfall and vegetation, which basically predicts the 
  vegetation response for a given rainfall amount. He has a publication and code, Adrian can inquire.
  
  
- The biggest item which came up today was that Adrian thinks the sampling approach is interesting.
  However, we thinks that we should actually try our analyses again, but this time using ALL the pixels.
  So for Veg * Wetness matrix on p18, we would be sampling ALL the pixels in each category. This is a pure
  geospatial approach, not a statistical one.

- He also suggested that we should make rasters* of total veg too, as we have done for inundation. This would
  be basically rasters of the Total_veg (Green + dead fractions) lower percentiles*, eg 5, 10, 20, 30, 50 percentiles.
  (50 basically being the median?). This percentile approach could be better than just taking the mean/median
  across the time series. The logic is that when the veg is really struggling, if there is still someting left,
  that can be a sign of a healthy ecossytem.


- With a raster of total veg across the time series, we could then do the analysis vs inundation using ALL pixels
  in each combo of veg type and wetness class. This could be quite a useful analysis.
  
- Similarly, Adrian liked the flood trend analysis on page 21. But he suggested that it should be done usign ALL the
  pixels in each category. This is a useful analysis for determining if the change in inundation is systematic or 
  stochastic. Currently, it's hard to conclude either way based on a small sample...

- Similarly, the plots on page 24 should be done for ALL pixels. In most cases, ALL pixel plots need to change, so that
  we don't see thousands of points, we just see a grey confidence interval band around a potential trend, and/or a 'heat
  map / kernel density' approach (lots of examples in remote sensing lit, include Adrian's work).

- Adrian also liked slide 25, which shows the correlation lags between veg cover and inundation lead time.
  However, again he suggested we should be doing this same analysis across all pixels in our 3 * 3 matrix of
  veg type * wetness. So that would give us a matrix of corrleation lags. He also thinks we should be using the
  total veg lower percentiles here, eg 5/10/30 %-iles (rather than just median cover across the time series).
  
- Slide 26 does show the matrix, but again we want that analysis done with ALL pixels in each category, and again
  using the total veg percentile (5/10/20) that shows the strongest relationship with inundation.
  
- RE the dashboards, these could be a good deliverable for the Gayini Managers, especially the Site-level dasboards (eg slide 28).
  But for a final submission, we need more info on the sites, eg we can combine info from Earnests attribute table
  compiled using nearmap data, with the RS output I have created, and then hopefully input from Gayini management, to 
  create a richer picture for each site. Each site could have a report .md/html file, which contains text for the context/
  history, and also includes the dashboards. We can work on designing the Report doc (incl the dashboards) as a key deliverable
  for Gayini.
  
- Choosing the summary stat for each year and across the time series can be tricky (eg mean, median, min, max, etc).
  The lower percentiles are similar to the min, but not as extreme, so we can try those and see how it goes. Our 
  anaylis can be inclusive, in that we want to store all the potential variables in our Database. We might need a separate
  DB for the full pixel extractions? Otherwise perhaps using CVS files is another option.
  
- Another point is that our analyses are mainly done across the whole time series (1988-2023). Can we try doign an analysis 
  for each year, just to explore the variation in the data more?

- Also, for the display of vegetation time series on the dashboards, we could try "anualizing" them, so they match the RS 
  Annual inundation time series.

- The veg plot should NOT say (green cover), because it includes dead veg too.
- The scatterplots on the dashboards should also use the Veg percentiles (5/10/20) next time (pick one across all).

- EG can some of the changes Earnest is detecting show up in the dashboard? Every site is different, so can RS help classify
  pixels based on change, in combo with land management history? We could use this approach to working with Gayini on 
  interpretting the site results, or making new sites based specifically on their management actions. These site results
  could be the basis of an article where Gayini staff are co-authors, providng vital context.

- RE the CSIRO HCAS and Biodiversity (LOOC-B) data, we shouldn't compare this with ground cover due to circularity. BUT, we can
  take the CSIRO variables as generalised measures of annual condition, and then compare it with inundation, which is totally
  independent. This could an interesting analysis, again we want to do it for ALL valid pixels, not subsampled.

- A very important point when interpreting vegetation change from RS data, is that we need to think about structure, 
  not just measures of condition from prett coarse satellties like Landsat. EG for each site and paddock, there may have 
  been gradual changes over time, shifting from cropping to grazing, and from little/no native veg to then native shrubs
  like chenopod re-establishing over time. EG if inundation does increase with management change, the veg structure* may
  change too. In the earlier part of the time series (when the sites were cropped), the veg cover signal from landsat 
  could be coming from irrigated cropping, eg wheat, cotton, etc! Then as grazing and inundation increase, the chenopod 
  shrubs could re-colonize the area aroun sites, and thus later in the time series, Landsat could be picking up ground
  cover signals from native veg. 

- Ultimately, Adrian suggests that using LS fractional cover data in this way might not work in they way we'd hoped to 
  actually tease out the details of water-veg dynamics that could be attributed to management change. But the "NULL" result
  could still be use to tell a story, EG: we might end of needing to use higher res data, such as LiDAR and nearmap, to track
  stucture over time, which may should a clearer response to management change.
